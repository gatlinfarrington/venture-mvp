Lemon Squeezy's Orders page answers "what sold today." Tax season, a buyer diligence request, or a product-by-product year review needs every paid order in a sheet you can query. This guide covers the official CSV export, what those columns mean, when the Orders API is the better path, and how a dedicated importer differs from pasting a snapshot.

RevenueSheet is pending Google Workspace Marketplace review. Nothing here claims the add-on is installable today. [Join the launch list](/#launch) if you want a heads-up when Free (one source, manual refresh) and paid scheduled sync open.

## Option 1: Export orders as CSV (official)

Lemon Squeezy documents a store-level export on the Orders page: click **Export**, and the CSV is emailed to the store owner ([Exporting Orders](https://docs.lemonsqueezy.com/help/orders/exporting-orders); checked Oct 13, 2026).

That CSV is a point-in-time snapshot. Useful for a backup or a one-off spreadsheet. Next month you export again, re-import, and reconcile any formulas or notes you added beside last month's rows.

### Columns worth mapping carefully

Per Lemon Squeezy's export docs (checked Oct 13, 2026), money fields arrive in **USD cents**. A $10.00 total is `1000`, not `10`. Divide by 100 before you chart revenue.

| Column | Notes (from LS docs) |
|---|---|
| `order_number` | Numerical ID shown in the dashboard and receipts |
| `product_name` / `variant_name` | What was purchased |
| `user_email` | Customer email |
| `currency` / `currency_rate` | Display currency at checkout; payments settle in USD |
| `subtotal` / `discount_total` / `tax` / `total` | USD cents |
| `tax_name` / `tax_rate` | e.g. VAT / GST / sales tax |
| `date_utc` | Order time in UTC |

Import with **File → Import → Upload** in Google Sheets and choose "Insert new sheet(s)." Keep the raw export tab untouched; build QUERY / SUMIFS on a second tab so a fresh paste does not wipe your formulas.

## Option 2: Walk the Orders API (when CSV is not enough)

If you need pagination, filters, or a script that can resume, Lemon Squeezy's API lists orders newest-first via `GET https://api.lemonsqueezy.com/v1/orders` ([List all orders](https://docs.lemonsqueezy.com/api/orders/list-all-orders); checked Oct 13, 2026). List endpoints use page-based pagination: `page[size]` is 1–100 (default 10), and responses include JSON:API `links.next` when more pages remain ([Requests](https://docs.lemonsqueezy.com/api/getting-started/requests); checked Oct 13, 2026).

That path is powerful and easy to get wrong:

- **Cents again.** Attribute amounts such as `total` and `total_usd` are documented in cents on the same orders endpoint.
- **Apps Script time limits.** A Google Apps Script execution stops after 6 minutes ([Quotas](https://developers.google.com/apps-script/guides/services/quotas); checked Oct 13, 2026). Large stores need a cursor (save `links.next` or `page[number]`) and a second run.
- **Auth.** API keys are secrets. Do not paste them into a cell.

A minimal mental model: page until `links.next` is absent, write one row per order, convert cents to dollars once, and never overwrite your formula tab.

## What a CSV (or homemade script) still leaves open

- Refunds that arrive after the export are not on that snapshot.
- Subscription MRR needs subscription status and interval fields, not only order totals — see [Lemon Squeezy MRR](/blog/lemon-squeezy-mrr).
- Combining Lemon Squeezy with Polar or Gumroad means aligning columns by hand — see [Combine sales platforms](/blog/combine-sales-platforms).
