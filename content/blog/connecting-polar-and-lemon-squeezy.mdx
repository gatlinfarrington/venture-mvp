Pro includes every supported source on a schedule. A practical order of operations:

1. Install the add-on and connect **one** source on Free. Confirm Backfill fills Orders and the Dashboard.
2. Upgrade to Pro, add the second source, and run Backfill again.
3. Check the Dashboard series colors (Lemon Squeezy is ink, Polar is signal green) so stacked MRR stays readable.

Refunds update existing rows by id. If a tab looks empty, see [Troubleshooting](/docs/troubleshooting) before rotating API keys. Per-source setup: [Lemon Squeezy](/docs/setup/lemon-squeezy), [Polar](/docs/setup/polar).
