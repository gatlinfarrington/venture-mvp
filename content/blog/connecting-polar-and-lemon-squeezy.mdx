Once paid plans open, Pro includes every supported source on a schedule (at launch). A practical order of operations:

1. Join the launch list, then install once the Marketplace listing is live and connect **one** source on Free. Confirm Backfill fills Orders and the Dashboard.
2. Upgrade to Pro, add the second source, and run Backfill again.
3. Check the Dashboard stacked MRR chart: Lemon Squeezy is near-black, Polar is medium gray, so each source stays readable in the stack.

At launch, refunds update the original order row instead of creating a duplicate. If a tab looks empty, see [Troubleshooting](/docs/troubleshooting) before rotating API keys. Per-source setup: [Lemon Squeezy](/docs/setup/lemon-squeezy), [Polar](/docs/setup/polar).
